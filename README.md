# Fra-JSON-til-API-JavaScript-med-nettside-2

Refleksjon
Hva er JSON?

JSON står for JavaScript Object Notation. JSON er et format som brukes til å lagre og utveksle data mellom programmer. Jeg har lært at JSON brukes mye i nettsider og API-er fordi det er lett for både mennesker og datamaskiner å lese. Dataene lagres på en strukturert måte ved hjelp av nøkler og verdier. I dette prosjektet brukte jeg JSON både til musikkdata og vitser.

Hvordan er JSON bygget opp?

JSON er bygget opp av objekter og lister. Et objekt inneholder ulike egenskaper med verdier, for eksempel navn, sjanger eller antall lyttere. Flere objekter kan ligge i en liste. I min JSON-fil om musikk lagret jeg flere artister i en liste. Hver artist hadde informasjon som navn, sjanger, land og antall lyttere. Dette gjorde det enkelt å hente ut informasjon senere med JavaScript.

Jeg lærte også at strukturen må være riktig. Hvis det mangler komma, klammeparenteser eller anførselstegn, vil ikke JSON-filen fungere.

Oppgave 1: Utforsk JSON

I denne oppgaven laget jeg min egen JSON-fil om musikk. Jeg valgte informasjon som var enkel å bruke videre i prosjektet. Filen inneholdt flere artister med ulike opplysninger. Målet med oppgaven var å forstå hvordan JSON er bygd opp og hvordan data organiseres.

Gjennom arbeidet lærte jeg forskjellen mellom objekter og lister. Jeg fikk også erfaring med å skrive JSON riktig og teste at strukturen fungerte.

Oppgave 2: Lister og oppslag

I denne oppgaven jobbet jeg med lister i JavaScript. Jeg testet hvordan jeg kunne hente ut informasjon ved hjelp av indeksnummer. Jeg fant første element, siste element og antall elementer i en liste.

Oppgaven hjalp meg med å forstå hvordan data lagres i lister og hvordan jeg kan hente ut bestemte verdier. Dette var viktig fordi JSON-data ofte består av lister med mange objekter.

Oppgave 3: Bruk JSON-filen du laget

I denne oppgaven leste jeg JSON-filen min i JavaScript. Jeg viste én artist, alle artistene og enkelte opplysninger fra filen. Her begynte jeg å forstå hvordan JSON-data brukes i faktiske programmer.

Jeg lærte hvordan JavaScript kan lese data og vise informasjon på nettsiden. Dette gjorde at jeg fikk bedre forståelse for hvordan nettsider henter og bruker data.

Oppgave 4: Utforsk vitsefilene

I denne oppgaven undersøkte jeg to ulike JSON-filer med vitser. Jeg fant den første vitsen, den siste vitsen og antall vitser. Jeg analyserte også hvordan filene var bygd opp.

Jeg oppdaget at den ene filen var enklere, mens den andre inneholdt mer informasjon. Dette gjorde at jeg forstod hvorfor datastruktur er viktig når man lager programmer som skal håndtere mange data.

Oppgave 5: Les vitsefilene i kode

Dette var en av de mest interessante oppgavene. Jeg laget en nettside som leser vitser fra en JSON-fil og viser dem på skjermen. Jeg brukte JavaScript til å hente inn dataene og presentere dem på en oversiktlig måte.

Nettsiden kunne vise alle vitser, velge en tilfeldig vits og søke etter bestemte ord. Jeg brukte både HTML, CSS og JavaScript i denne oppgaven.

Gjennom arbeidet lærte jeg hvordan flere teknologier kan samarbeide for å lage en fungerende nettside.

Oppgave 6: API-lab

I den siste oppgaven jobbet jeg med API. Jeg brukte TheCatAPI for å hente tilfeldige kattebilder fra internett. Dette var annerledes enn de tidligere oppgavene fordi dataene ikke kom fra en lokal fil.

Jeg lærte hvordan fetch() brukes til å hente data fra et API. Jeg laget en knapp som lastet inn et nytt bilde hver gang brukeren trykket på den. Oppgaven ga meg forståelse for hvordan moderne nettsider henter informasjon fra ulike tjenester på internett.

Hva var vanskelig?

Det vanskeligste var å koble sammen HTML, CSS, JavaScript, JSON og API-er. Noen ganger fikk jeg feil i koden som var vanskelige å finne. Jeg brukte også tid på å forstå fetch()-funksjonen og hvordan data hentes inn. I tillegg hadde jeg utfordringer med GitHub, spesielt når jeg skulle laste opp filer og koble prosjektet til riktig repository.

Hva er forskjellen mellom en lokal JSON-fil og et API?

En lokal JSON-fil ligger lagret i prosjektmappen og inneholder data som er skrevet på forhånd. Hvis innholdet skal endres, må filen redigeres manuelt.

Et API henter data fra en ekstern tjeneste på internett. Informasjonen kan oppdatere seg automatisk og være forskjellig hver gang man bruker tjenesten. I dette prosjektet brukte jeg lokale JSON-filer til musikk og vitser, mens jeg brukte API til å hente kattebilder.
